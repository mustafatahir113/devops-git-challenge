## Reflection Questions

1. What is the purpose of Git stash?
Git stash temporarily saves uncommitted changes so the working directory can be cleaned.

2. Why are branches useful?
Branches allow developers to work on separate changes without directly affecting another branch.

3. What causes a merge conflict?
A merge conflict occurs when Git cannot automatically reconcile competing changes, such as edits to the same lines.

4. Why use a pull request?
A pull request allows changes to be reviewed before they are merged into the target branch.
